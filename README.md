# Co-Parenting

A [Chickadee Bandit](https://chickadeebandit.com/app-library/co-parenting) app.

Shared custody coordination for split households — per-child standing schedules (alternating weeks, 2-2-3, alternating weekends, 2-2-5-5, 3-4-4-3, or your own cycle) that BOTH parents countersign before they take effect, countersigned one-off swaps whose terms are frozen server-side at approval, a message log that cannot be edited or deleted after sending, and handoff notes. Every agreed version is kept; custody days are worked out on the server from what was agreed and flow to the household Calendar, so kids always know where they are.

## Features

- Per-child standing schedules, countersigned by both parents before they apply.
- Countersigned one-off swaps.
- Every agreed version is kept.
- An audited message log with content checksums, and handoff notes.
- Custody days flow to the shared calendar and Today view.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-co-parenting/releases/latest/download/bundle.json
```
